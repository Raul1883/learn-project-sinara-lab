# AOP

Реализован контроллер, сервис и аспект, для контроля запросов.
Используется стороння библиотека bucket4j для контроля количества запросов.

Классы **MyService** и **MyController** возвращают информацию о имени spring приложения.

## ServiceLimiter
Аспект, ограничивающий количество запросов. При каждом вызове методов класса MyService при помощи bucket4j рассчитывается доступность методов API. Настройки bucket-а находятся в properties файле.  
В случае превышения количества запросов, выбрасывается кастомное 429 исключение TooManyRequest
