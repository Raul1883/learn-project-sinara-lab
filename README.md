# Events & listeners

Реализован контроллер, сервис и dto сущность для отладки. Создано 3 события - обычное сообщение, успешная транзакция, откат транзакции (POJO).

Создано три слушателя:

## SimpleListener  
Простой слушатель, логирует информацию о сообщении

## TransactionalListener
Слушатели для операций с транзакциями. Один - после успешного коммита, второй - при откате.

## Асинхронный слушатель  
Работает асинхронно, аналогичен SimpleListener
